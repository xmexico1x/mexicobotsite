Privacy Policy

MexicoBot Stream Tools — last updated 14 September 2026

1. Who this covers

MexicoBot Stream Tools ("the app") is a private tool run on the owner's own computer by the owner of the TikTok account @lvlexico1 / xmexico1x. It has no other users and no server that other people connect to.

2. What it stores, and where

Everything the app keeps is stored locally on the owner's own computer. Nothing is uploaded to any server belonging to the app, because there is no such server.

  • TikTok access tokens for the owner's own account, kept locally so the app can upload clips without asking for a new sign-in every time.
  • Video clips cut from the owner's own livestreams.
  • Public livestream chat from the owner's own streams, used to run the stream's chat features. It stays on the owner's computer.

3. What it does NOT do

  • It never collects or stores anyone's password.
  • It never sells, rents or shares any data with anyone.
  • It uses no advertising, no analytics and no third-party tracking.
  • It reads no other person's TikTok account, private messages or private data.

4. TikTok data

The app uses TikTok's official APIs only to upload the owner's own videos to the owner's own account, and to read the basic profile information TikTok returns at sign-in. Access can be revoked at any time from the TikTok app under Settings, Security and permissions, Manage app permissions. Revoking it stops all access immediately.

5. Deleting data

Deleting the app's folder on the owner's computer removes every stored token and clip. There is nothing held anywhere else to delete.

6. Children

The app is not directed at children and is used only by its owner.
